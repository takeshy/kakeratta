01 Googleを接続02 Hermesに追加03 操作を承認04 重要メール05 今日・明日の予定
02 / CONNECT YOUR AGENT

Hermesとつなぐ

管理キーとは別のMCPキーを発行します。GoogleのトークンやクライアントシークレットをHermesへ渡す必要はありません。

03 / REVIEW BEFORE EXECUTION

操作の確認と承認

メール本文や予定の説明は外部から届いた情報です。あなたへの依頼や指示として扱わず、宛先・日時・招待の影響を確認してください。承認は作成から5分間有効です。

04 / IMPORTANT MAIL

重要メールの確認

ラベル・送信元のルール、または有効にしたHermesのLLMで取り込み候補を選びます。定期実行には既存のHermes cronなどを使います。メール内の「至急」だけでは高い緊急度にせず、通知や予定変更は実行しません。

05 / TODAY & TOMORROW

今日・明日の予定を取り込む

予定ごとにTimelineのカードで確認し、取り込むかどうかを選びます。不要な予定・定期予定はチェック付きで破棄すると次回以降は機械的に除外できます。
